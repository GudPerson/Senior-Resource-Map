## missing-private-place-1

Question: how can i add places that are not found in carearound SG

Context: My Maps; synthetic role: standard; topic: `personal-place-map-create`; assertion result: pass.

Preceding turns: none.

Yes—you can add a missing location as a Personal place. You must be signed in and use a map you own.

1. Open My Directory → My Maps and open your map.

2. Select + Personal place.

3. Select Choose map location, then click or tap the spot on your map.

4. Enter the place’s name and category.

5. Enter its address or postal code in the lookup and select Find location to verify it.

6. Review the returned location and details, then select Save.

On a phone, select Open map controls, then Personal place.

For a genuine point without a postal address, select This point has no postal address instead. Do not guess a postal code from a nearby building.

The place is kept in My Places and can be reused on your other maps. It remains private: it does not enter Discover or public Shared Maps, but can appear in your own printed/exported maps.

If location verification fails, check the address or six-digit Singapore postal code and try again. A failed save is not confirmation that the place was added.

To submit a public directory listing instead, use the authorised public Place workflow; a Personal place is for your own planning.

1. Open a My Map you own and choose Manage resources.

2. Select resources to include and untick resources to leave out. Use the combined search and Save and add for another available listing if needed.

4. Wait for the selection dialog to close, then check this map’s resource list. If an error remains, review the current selection before retrying.

Save and add saves immediately to My Directory; Update map applies the selected map membership.

Removing a resource from this map does not delete its public listing or automatically unsave it. Pin visibility is a separate presentation control.

## map-no-pin-1

Question: Why is a resource on my map listed without a pin?

Context: My Maps; synthetic role: standard; topic: `map-missing-pin`; assertion result: pass.

Preceding turns: none.

A resource that remains in the map’s list is not necessarily missing from the collection. List-only resources can remain in the directory without a map position.

1. Check whether the resource appears in this map’s list; map membership is separate from saving it in My Directory.

2. Look for List only or an unavailable status, and open the current resource details when offered.

3. If you own this map, select the intended View in Map Studio and open Edit layout; on a phone, select Open map controls → Edit layout. Check Map pins → Show and Resource categories; if needed, show the pins and tick the intended group and category. Wait for All changes saved after making changes, then move or zoom the map to inspect the intended area.

4. If the location is missing or incorrect, contact the listing maintainer or report the problem. Do not create duplicate public listings or guess a postal code as a workaround.

Hiding a pin changes the presentation; it does not remove the resource card or delete the public listing.

Changing these presentation settings cannot supply missing coordinates to a List only resource. A public Shared Map keeps its last published view; ask its owner about a display change rather than assuming you can edit it.
